# Storybook Core

`@nicolassancho/storybook-core` is a set of accessible React components styled with Tailwind CSS v4,
built to render from Next.js Server Components. This site is its documentation: every component has
live examples, props and tests.

```bash
npm install @nicolassancho/storybook-core
```

## Where to go

- [Consumers](?path=/docs/consumers--docs): install, set up the styles and dark mode, and use the
  components from Next.js.
- [Foundations / Colors](?path=/story/foundations-colors--palette): the palette in light and dark,
  and the contrast of each text color.
- **Atoms, Molecules, Organisms and Layouts** in the sidebar: the components, from a Button to a
  full ProductGrid.

Every component supports a light and a dark theme. Use the **Theme** switch in the toolbar to try
both, or choose System to follow your operating system.
